YAML-based API testing

Write API tests as readable specs. Run them anywhere.

SPEQ is an open-source CLI runtime for declarative API tests. It validates YAML test suites, executes them deterministically, and produces summary and Allure-compatible reports for local development and CI.

Start the quickstart Install SPEQ

For API teams

Keep request flows, assertions, fixtures, and reusable module actions in versioned YAML files. SPEQ is designed for service repositories and dedicated API test repositories.

For CI pipelines

Run the same specs in GitHub Actions with generated environment files, uploaded summaries, logs, and Allure artifacts.

Core commands

speq init --mode in-repo speq validate --speq-root .speq --format json speq run --speq-root .speq --env ci --report summary speq report --format allure --summary .speq-artifacts/results/summary.json

MVP v1.0.0 scope

This site documents the public MVP path: install the CLI, run a first spec, generate CI environment YAML from GitHub Secrets, and use the canonical JSONPlaceholder examples.
