Install

Install the SPEQ CLI.

The SPEQ CLI is the runtime for validation, execution, reports, and CI. Install it locally for authoring tests, or let the GitHub Action install it in CI.

macOS and Linux with Homebrew

brew tap speq-tms/tap https://github.com/speq-tms/homebrew-tap
brew install speq

Check the installation:

speq help
speq version

GitHub Release artifacts

Release binaries are published from speq-cli releases. Download the archive for your platform and verify it with the matching .sha256 file.

  • speq-linux-x86_64.tar.gz
  • speq-darwin-x86_64.tar.gz
  • speq-darwin-aarch64.tar.gz
  • speq-windows-x86_64.zip

Do not use docs, runner, or Homebrew formula versions that point to missing release artifacts.

Manual install from an archive

  1. Download the release archive for your operating system.
  2. Extract the archive.
  3. Move the speq binary into a directory on your PATH.
  4. Run speq help and speq version.

Windows

For MVP v1.0.0, Windows install is zip/manual only. Download speq-windows-x86_64.zip from GitHub Releases, extract it, and add the extracted folder to your PATH. 

speq help
speq version

No Windows package manager install path is documented for MVP v1.0.0.

CI install

In GitHub Actions, use speq-tms/speq-github-runner@v1 with setup-method: release or mode: run. See CI & Secrets.
