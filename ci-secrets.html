CI & Secrets

Generate SPEQ environments inside GitHub Actions.

Do not commit real secrets. Store secret values in GitHub Secrets, generate the SPEQ environment YAML during the job, run SPEQ, and upload reports as CI artifacts.

Recommended secret names

  • SPEQ_CI_BASE_URL: target API base URL for CI.
  • SPEQ_CI_SOURCE_HEADER: optional non-sensitive request source marker.
  • SPEQ_CI_AUTH_TOKEN: optional bearer token or API token for authenticated APIs.

For public APIs such as JSONPlaceholder, SPEQ_CI_AUTH_TOKEN is not required.

Generated environment YAML

Create the file inside the runner workspace. Do not print the generated file to logs.

mkdir -p .speq/environments
cat > .speq/environments/ci.yaml <<EOF
name: ci
baseUrl: ${{ secrets.SPEQ_CI_BASE_URL }}
headers:
  authorization: "Bearer ${{ secrets.SPEQ_CI_AUTH_TOKEN }}"
  x-source: speq-ci
EOF

If your API does not require a token, omit the authorization header instead of committing a fake value.

GitHub Actions workflow

name: speq smoke

on:
  pull_request:
  push:
    branches:
      - main

jobs:
  speq:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Generate SPEQ CI environment
        run: |
          mkdir -p .speq/environments
          cat > .speq/environments/ci.yaml <<EOF
          name: ci
          baseUrl: ${{ secrets.SPEQ_CI_BASE_URL }}
          headers:
            authorization: "Bearer ${{ secrets.SPEQ_CI_AUTH_TOKEN }}"
            x-source: speq-ci
          EOF

      - uses: speq-tms/speq-github-runner@v1
        with:
          mode: run
          speq-root: .speq
          env: ci
          tags: smoke,api
          artifacts-prefix: speq
          summary-output: .speq-artifacts/results/summary.json
          allure-dir: reports/allure
          upload-artifacts: "true"

Runner modes

Setup only

- uses: speq-tms/speq-github-runner@v1
  with:
    mode: setup
    setup-method: release
    cli-version: latest

Custom orchestration

- uses: speq-tms/speq-github-runner@v1
  with:
    mode: custom
    custom-command: |
      speq validate --speq-root .speq --format json
      speq run --speq-root .speq --env ci --report summary --output .speq-artifacts/results/custom-summary.json
