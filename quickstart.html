Quickstart

Run your first SPEQ API test.

This guide creates a small in-repository SPEQ project, validates it, and runs a smoke test against a public API.

  1. Install the CLI

    On macOS or Linux with Homebrew:

    brew tap speq-tms/tap https://github.com/speq-tms/homebrew-tap
brew install speq

    For Windows, download the Windows zip from GitHub Releases and add the extracted folder to your PATH.

  2. Create a SPEQ project

    Inside the service repository you want to test, initialize an in-repository SPEQ layout:

    speq init --mode in-repo

    This creates a .speq directory with a manifest, environments, suites, and reports folders.

  3. Configure an environment

    Edit .speq/environments/ci.yaml with your API base URL:

    name: ci
baseUrl: https://jsonplaceholder.typicode.com
headers:
  x-source: speq-quickstart

  4. Add a smoke test

    Create .speq/suites/posts_smoke.yaml:

    id: "posts.smoke.get-by-id"
title: "Posts smoke: get post by id"
tags:
  - smoke
  - api
steps:
  - type: api
    name: "GET /posts/1"
    method: GET
    url: "/posts/1"
    assert:
      - type: status
        expected: 200

  5. Validate and run

    speq validate --speq-root .speq --format json
speq run --speq-root .speq --env ci --tags smoke,api --report summary --output .speq-artifacts/results/summary.json
speq report --speq-root .speq --format allure --summary .speq-artifacts/results/summary.json
